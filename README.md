# ODISEE Student Progression Research

## Project Overview

This repository contains research and resources for improving programme-level academic success at Odisee through a systems-thinking approach. The project is conducted as part of an MSc thesis in Educational Sciences at Vrije Universiteit Brussel (VUB).

**Project Title:** A Systems-Thinking Approach to Improving Programme-Level Academic Success at Odisee

**Institution:** Vrije Universiteit Brussel (VUB)  
**Programme:** MSc Educational Sciences  
**Researcher:** Chithra Rani Jayaraman  
**Academic Year:** 2025-2026

## Project Description

Student progression through higher education programmes is influenced by complex, interconnected factors at individual, programme, and institutional levels. Rather than viewing progression challenges in isolation, this research employs systems-thinking to:

1. **Understand** the complex relationships between factors affecting student success
2. **Identify** leverage points for effective intervention
3. **Design** evidence-based interventions aligned with the systems model
4. **Implement** and evaluate changes in institutional practice

## Research Methodology

This research combines:
- **Qualitative Approaches:** Stakeholder interviews, focus groups, document analysis
- **Quantitative Methods:** Progression metrics, institutional data analysis
- **Systems Mapping:** Causal loop diagrams and systems models
- **Participatory Action Research:** Co-design of interventions with stakeholders

## Key Research Questions

1. What are the primary factors affecting student progression through Odisee programmes?
2. How do these factors interact to create systemic patterns in student success?
3. What evidence-based interventions can effectively address progression challenges?
4. How can institutional systems be better coordinated to support student success?
5. What metrics best indicate programme-level health and student progression effectiveness?
